# AI-Summit-Biasbusters
## Setup Expo and Launch Frontend


### Frontend

Prerequisites :
- Node.js installed
- Expo CLI installed globally (`npm install -g expo-cli`)

1. **Clone the repository:**
    ```sh
    git clone git@github.com:Degnel/AI-Summit-Biasbusters.git
    cd AI-Summit-Biasbusters
    ```

2. **Install dependencies:**
    ```sh
    npm install
    ```

3. **Start the Expo server:**
    ```sh
    expo start
    ```

4. **Run the application:**
    - Open the Expo Go app on your mobile device.
    - Scan the QR code generated by the Expo server.



### Backend

1. **Create and activate a virtual environment:**
    ```sh
    python3 -m venv venv
    source venv/bin/activate
    ```

2. **Update and install necessary packages:**
    ```sh
    sudo apt-get update
    sudo apt-get install portaudio19-dev python3-dev
    sudo apt install ffmpeg
    sudo apt install libgl1-mesa-glx
    sudo apt update && sudo apt install redis
    ```

3. **Install Python dependencies:**
    ```sh
    pip install redis
    pip install RealTimeSTT
    ```

4. **Export your Mistral API key:**
    ```sh
    export MISTRAL_API_KEY=<your_api_key>
    ```
.
We also provide code to benchmark the model we used over 100 first aid use cases. It can be found in the backend/llm.py file.
